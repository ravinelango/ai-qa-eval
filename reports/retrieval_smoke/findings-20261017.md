## Cautions for reading the results

- **HP14 is a fragile pass.** `hybrid` found it at rank 5, the last place that counts,
  while `hybrid_rerank` put it first. A small change could flip it, so it is not a
  stable pass.
- **Some held-out paraphrases follow the regulation's wording closely**, for example
  HP03 ("personally responsible ... electronic signature") and HP04 ("before giving a
  new hire an electronic signature"). That makes them easier than real users'
  questions. It is acceptable for a plumbing check. The Phase 1b golden set should
  include messier, real-user phrasing.
- **The hit rule is lenient.** Any expected section anywhere in the top 5 counts, so
  rank 1 and rank 5 score the same. The Phase 1b evaluation should also report
  rank-aware measures such as reciprocal rank.
- **These are plumbing checks.** Hit counts from them are never headline results, in
  the README or anywhere else.

## The four original paraphrases that both rankings miss

Ranks are over all 149 chunks, from the diagnostics in
[`20261015T003855Z-e3adfd.md`](20261015T003855Z-e3adfd.md). That run was at
`b1e1a3f`, before the citation fix. None of these four questions cites a section,
so the fix does not affect them: the next run changed only L11. The reranker's own
ranks below its top 5 were not saved.

| Query | Expected | Embedding rank | Keyword rank | Hybrid rank | Top 5 with `hybrid_rerank` |
|---|---|---|---|---|---|
| P01 | `21cfr11/11.10(e)` | **1** | 52 | 22 | miss |
| P08 | `21cfr11/11.30` | **4** | 46 | 8 | miss |
| P11 | `fda-part11-scope-2003/III.C.2` | 38 | 22 | 25 | miss |
| P14 | `fda-data-integrity-2018/III.5` (or §11.100(a), §11.300(a)) | **1** | 14 (an alternative; III.5 itself is outside the top 50) | 27 | miss |

- **P01** ("log of every change, with the earlier value"). The embedding ranks
  § 11.10(e) first. The question shares almost no words with the regulation, so the
  keyword ranking puts it 52nd, and fusion drops it to 22nd. The hybrid top 5 is made
  up of audit-trail passages from the guidance. The first of them, the 2003 guidance's
  III.C.2, names § 11.10(e). **Known narrow expectation:** III.C.2 arguably answers the
  question too, but the expectation is left as written.
- **P08** ("records over the internet to a system we don't control"). The
  question never says "open system" and the regulation never says "internet". Even
  so, the embedding ranks § 11.30 fourth. The keyword ranking puts it 46th, and
  fusion pushes it to 8th.
- **P11** ("FDA action over missing change histories while it re-examines Part 11").
  The embedding ranks the expected chunk only 38th. The top results are other
  sections of the same 2003 guidance: the right document but the wrong section. The
  corpus never says "change histories", and the question combines two ideas. This is
  the only one of the four that every ranking misses.
- **P14** ("several analysts using the same username"). The embedding ranks the shared
  login section (III.5) first. The keyword ranking places it outside its top 50,
  pulled toward computer software assurance chunks by "software". Fusion drops it to
  27th.

**What this shows.** Lay wording against regulatory terms is the common cause, as
the other analysis found. But for P01, P08 and P14, it defeats the keyword ranking,
not the embedding: the embedding alone found them at ranks 1, 4 and 1, and they were
hits in the first, embedding-only run. Fusing in a keyword ranking that shares no words
with the question pushed them out of the top 5, and the reranker did not restore
them. Only P11 is a miss for the embedding as well. So the original set's failure is
a real weakness of the hybrid ranking on everyday wording. Mostly it is not bad
questions, and mostly it is not the embedding.

## Possible next steps (none approved)

Any change would again be designed with these four queries in view. It would need to
be fixed in advance and judged on a new third question set, written before its first
run and approved by the owner. The two used sets stay as they are.

- **Plain-language synonyms or query expansion** for key regulatory terms (open
  system, audit trail, shared login), so the keyword ranking can match lay wording.
- **Keeping the embedding ranking's top results when the keyword ranking finds
  nothing.** For example, fall back to the embedding ranking with citations first,
  or weight the fusion by how much the keyword ranking matched. This targets the
  mechanism above, but any weight would be a new setting to fix in advance.
