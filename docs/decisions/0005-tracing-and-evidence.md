# 0005 — Tracing and saved evidence

**Status:** accepted (Phase 0) · **Date:** 2026-10-12

## Decision
- **One tracing primitive**: `Tracer.observe(name, kind=..., input=..., metadata=...,
  model=..., attributes=...)` as a context manager (`apps/core/tracing/base.py`). Kinds
  include `generation`, `retriever`, `tool`, `guardrail`, `evaluator`, so retrieved chunk
  IDs (Phase 1a), tool calls and judges need no new methods. Exceptions are recorded as
  `ERROR` with a status message, then re-raised. `TraceAttributes` carries prompt version,
  run ID, variant and tags to nested observations.
- **Backends**: `none` (default; claims no trace IDs), `local` (JSONL file, no service),
  `langfuse` (Langfuse Cloud, SDK v4). Only `langfuse_tracer.py` imports Langfuse.
- **Trace IDs are ours**: W3C-format IDs are generated by the wrapper and passed to
  Langfuse as the trace context, so the same ID appears in run files, local trace files
  and Langfuse.
- **Run files are the evidence** (`apps/core/evidence.py`, schema version 2). Each holds
  the manifest (git SHA and dirty flag, models-config hash, pricing date, cache policy,
  prompt version, `synthetic` flag) and, per call: the resolved settings it ran with
  (`CallSettings`: provider, model ID, effort, max_tokens, temperature, timeout, retry
  policy, pricing rates and date), the full request, the response or error, every failed
  attempt with its error, measurements and the trace ID. The config hash identifies the
  settings; `CallSettings` preserves their values. This works with any tracer, including
  `none`.
  Langfuse links are supplementary: the Hobby plan keeps 30 days of data, so reports must
  stand alone.
- **Redaction.** Entry points call `configure_logging(secrets)`: a filter sanitizes each
  record (message, chained exception text, stack info) and a formatter redacts the full
  output. Run files and local trace files are written through the same pattern-based
  redaction for credential-shaped strings.
- **Offline tests and proxies.** langfuse 4.17 always builds an internal
  `httpx.AsyncClient` from environment proxy settings, which cannot be injected. The
  offline tests inject a `trust_env=False` client and construct the SDK with proxy
  variables cleared; all integration tests run under a hostile SOCKS proxy env.
- **Synthetic vs. evidence**: runs from the fake provider set `synthetic: true` and say so
  in their notes. They demonstrate plumbing and never appear as results in reports.
