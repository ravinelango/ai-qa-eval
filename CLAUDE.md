## Authorship
- Commit as the repository owner: set `git config user.name "Ravin Elango"` and
  `git config user.email "elravin83@gmail.com"` in the repo before the first commit
  of a session. Author and committer must both be Ravin Elango.
- Do not add a `Co-Authored-By: Claude` trailer to commit messages.
- Author and owner fields (`pyproject.toml`, data and spec files, docs) name Ravin
  Elango. Where a field records the provenance of content Claude drafted, such as
  `authored_by` in `evals/dev_checks/`, also say it was drafted by Claude Code and
  whether a human has reviewed it.
